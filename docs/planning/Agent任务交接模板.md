# Agent 任务交接模板

```text
任务 / 批次 ID：
所有者 / 协作角色：
范围：
writeScope（精确目录或文件）：
readScope / forbiddenScope：
前置 accepted 批次及契约版本：
相关 UX flow/screen/state/acceptance ID：
候选标识（commit 或文件 SHA-256）：
变更摘要 / 兼容与数据影响：
G1 自检：命令、环境、案例、结果、报告路径：
未运行项及原因：
问题：S0/S1/S2/S3、影响、建议、待用户裁定项：
正式测试与临时文件索引：
恢复 / 回退方法：
请求总负责人核对的内容：
G2 总检结论与证据：
G3 用户复核结论、日期及对应候选：
状态 / 下一步 / 可独立继续的工作：
```

提交前必须把用户可见新名称、未决行为和外部授权缺口单独列出。内部代码命名按规范，不要求用户逐项批准。文件所有权不能跨 Agent 重叠；共享文件由总负责人或指定整合者写入。
