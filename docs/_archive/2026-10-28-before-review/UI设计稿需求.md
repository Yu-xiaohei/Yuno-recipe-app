## P0 · 启动页

**UX**
- 冷启动展示；同步 `version.json`；成功或降级后淡出进主页（约 0.3s 内文案才出现，避免闪）
- 全部失败：进主页 + 离线提示，**不挡进入**

**布局**
```
[edge-to-edge 页底，浅 #F7F7F8 / 深 #000]
        [App 图标 88–96dp]
        「于の食谱」
        [柔光圆环 Spinner · 主色渐变]
        「正在同步餐谱数据…」（延迟 300ms 出现）
```

**状态**：默认 / 深色 / 超时仍展示但不永久阻塞

## P2 · 日历

**UX**
- 顶栏月份切换（‹ 10 月 ›）+ 日期搜索框（`2026-10-25` 或自然日）

## P3 · 配餐编排（玻璃抽屉 · 核心新流程）

**UX**
1. 选日期（默认今天）+ 选餐次 chips：早 / 午 / 晚（单选）
2. 已选列表：菜谱条目 + 零散食材条目
3. 每条默认重量 = 菜谱 `totals.weight`；点「改重量」→ P4
4. 「＋ 添加菜谱 / 零散食材」→ 选择页（可做 P3b）
5. 底部合计条：总重 · 热量 · 三大营养
6. 「生成并保存」→ 写入每日配餐 → 进 P5

**布局（玻璃抽屉）**
```
          ╭────────────────────╮  ← 抓手
          │  生成配餐           │
          │  10月26日 · [早][午][晚] │
          │  已选 · 3           │
          │  ┌────────────────┐ │
          │  │ 蛋炒饭      410g│ │
          │  │ 菜谱·默认     [改重量]│
          │  └────────────────┘ │
          │  ┌────────────────┐ │
          │  │ 西红柿鸡蛋汤  320g│ │
          │  └────────────────┘ │
          │  ┌────────────────┐ │
          │  │ 米饭+芹菜    180g│ │
          │  │ 零散食材        │ │
          │  └────────────────┘ │
          │  ┌ ─ ─ ─ ─ ─ ─ ─ ┐ │
          │  │＋添加菜谱/零散   │ │
          │  └ ─ ─ ─ ─ ─ ─ ─ ┘ │
          │  合计 910g · 728kcal │
          │  [     生成并保存    ]│
          ╰────────────────────╯
     （背景压暗 + 渐进模糊）
```

**状态**：空选择（CTA 禁用）/ 加载 / 保存成功（对勾反馈）

**P3b 添加菜谱/零散食材（二级）**
- 分段：`菜谱` | `零散食材`
- 菜谱：搜索 + 列表勾选（显示默认重量）
- 零散食材：名称 + 每100g 可查/可填 + 克数
- 底栏「添加到配餐（n）」

## P4 · 改重量（弹层）

**UX**
- 标题「调整《蛋炒饭》总重量」
- 大数字可拖/步进；默认 410 g（菜谱内置）
- 滑条建议范围 50%–150% 默认值
- 下方 **预览**：按 `healthWeight` 缩放后关键食材克数变化（如 米饭 130→160、猪肉 30→24）
- `locked` 食材标「不缩放」
- 确认 / 重置 / 取消

**布局**：小玻璃抽屉（约 40% 屏高）+ 大数字 + 滑条 + 两列预览表
