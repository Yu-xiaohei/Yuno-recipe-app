# 接口与字段清单

> 「于の食谱」全量数据字段 · 网络接口 · 本地接口  
> 用途 = 这个字段/接口干什么；调用方 = 谁在什么场景用它。

---

## 1. 餐谱 JSON `recipes/<id>.json`（schema v2）

### 1.1 顶层

| 字段 | 类型 | 用途 | 调用/使用处 |
|---|---|---|---|
| `schemaVersion` | int | 解析协议版本；`2` 表示含 healthWeight | `Migrator` / `RecipeParser` 判断解析分支 |
| `id` | string | 餐谱唯一标识（slug，同文件名） | 列表路由、详情参数、云端索引对照、草稿另存 |
| `name` | string | 菜名 | 列表卡片标题、详情大标题、搜索匹配 |
| `type` | string | 资料类型，现固定 `dish` | 预留扩展（未来套餐/食材卡） |
| `serving` | int | 几人份（默认 1） | 份量缩放的基准；详情页显示 |
| `standard` | string | 口径类型 `MIXED` 等 | 详情页来源说明；预留多口径 |
| `dishType` | string? | 分类：肉菜/素菜/汤/主食/混搭/小吃/饮品 | 列表分类 chips 筛选 |
| `tags` | string[]? | 自由标签 | 列表标签筛选、卡片角标 |
| `summary` | string? | 列表副标题一句话 | 列表卡片第二行 |
| `image` | string? | 菜谱图路径/URL；`null` 显示占位 | 详情页顶图、列表缩略 |
| `ingredientGroups` | array? | 食材分组（主料/辅料/调味） | 详情明细区分组渲染（预留） |
| `totals` | object | 全餐合计营养 | 详情总览卡、列表摘要、目标对照 |
| `targets` | object | 门槛/达标状态 | 详情目标对照条、超限标红 |
| `macroRatio` | object | 供能比 | 详情供能比条 |
| `items` | object[] | 食材明细 | 详情明细表、搜索、权重调配、缩放 |
| `notes` | string[] | 数据说明 | 详情「数据说明」折叠区 |
| `sources` | object[] | 原始来源链接 | 详情「数据来源」外链 |
| `generatedAt` | string | 生成时间 ISO | 详情头部、列表排序 |
| `generatedBy` | string | 生成工具/模型 | 详情生成信息 |
| `user` | string | 生成者 | 详情生成信息 |

### 1.2 `totals`

| 字段 | 单位 | 用途 | 使用处 |
|---|---|---|---|
| `weight` | g | 总重 | 总览卡、列表、份量缩放基准 |
| `energy` | kcal | 总热量 | 总览卡、列表、调配基准、热量区间筛选 |
| `carb` | g | 碳水 | 合计行、供能比 |
| `protein` | g | 蛋白 | 同上 |
| `fat` | g | 脂肪 | 同上 |
| `vitaminC` | mg | 维生素 C | 合计行（营养表代表列） |
| `fiber` | g | 膳食纤维 | 合计行 |
| `sodium` | mg | 钠 | 合计行、超限提示参考 |

### 1.3 `targets`

| 字段 | 用途 | 使用处 |
|---|---|---|
| `energyMax` / `energyBest` | 热量上限/最佳 | 目标对照进度条 |
| `weightMax` / `weightBest` | 重量上限/最佳 | 同上 |
| `energyOk` / `weightOk` | 是否达标 | 红/绿状态点 |
| `doseStatus` | `BELOW_RANGE`/`OUT_OF_RANGE`/`OK`… | 详情剂量提醒条文案 |

### 1.4 `macroRatio`

| 字段 | 用途 | 使用处 |
|---|---|---|
| `carbPct` / `proteinPct` / `fatPct` | 供能比百分数 | 供能比三段条 + 数字 |

### 1.5 `items[]` 每一项

| 字段 | 类型 | 用途 | 使用处 |
|---|---|---|---|
| `name` | string | 食材名 | 明细行、搜索、权重对照 |
| `weight` | number | 本菜用量 g | 明细行、缩放、调配 |
| `healthWeight` | number | 营养权重 0.01–1.00 | 目标调配算法；详情只读展示 |
| `locked` | bool? | 不参与缩放 | 调配时跳过 |
| `category` | string? | 类目（蔬菜/主食/调味…） | 明细筛选、调配展示分组 |
| `energy`/`carb`/`protein`/`fat`/`vitaminC`/`fiber`/`sodium` | number | 本菜该食材营养量 | 明细展开行 |
| `source` | string | 取数口径文字 | 明细展开行来源 |
| `per100` | object | 每 100g 参考值（同营养键） | 明细展开「每 100g」；缩放重算依据 |

### 1.6 `notes[]` / `sources[]`

| 字段 | 用途 | 使用处 |
|---|---|---|
| `notes[]` | 文字说明 | 详情折叠区 |
| `sources[].name` | 来源名 | 外链列表文案 |
| `sources[].url` | 原始链接 | 点击系统浏览器打开 |

## 2. 菜谱索引 `recipes/index.json`

| 字段 | 用途 | 调用/使用处 |
|---|---|---|
| `schemaVersion` | 协议版本 | 解析器 |
| `version` | 菜谱库版本号 `YYYY.MM.DD.N` | 与本地比对是否拉新 |
| `updatedAt` | 更新时间 | 设置/同步日志展示 |
| `recipes[]` | 轻量摘要列表 | 不下载全文即可列列表、算 diff |
| `recipes[].id` | 餐谱 id | 下载 URL / 增量 diff |
| `recipes[].file` | 文件名 | 拼下载地址 |
| `recipes[].name` | 菜名 | 列表即时渲染 |
| `recipes[].dishType` / `tags` / `summary` / `image` | 索引冗余 | 列表筛选/展示（可与全文不一致时以全文为准） |
| `recipes[].energy` / `weight` / `serving` | 摘要营养 | 列表卡片数字 |
| `recipes[].generatedAt` | 生成时间 | 默认排序 |

## 3. 总控版本 `version.json`

| 字段 | 用途 | 调用/使用处 |
|---|---|---|
| `schemaVersion` | 协议版本 | 解析器 |
| `app.versionName` | 展示版本 `主.次.修` | 设置页、更新弹窗标题 |
| `app.versionCode` | 内部整数版本 | **更新判定**（与本地比较） |
| `app.minSupported` | 最低可用版本 | 低于此值强制升级，不可跳过 |
| `app.apkUrl` | 安装包下载地址 | 更新弹窗确认后下载 |
| `app.changelogUrl` | 更新日志地址 | 设置 →「更新日志」WebView |
| `app.notes` | 本次更新一句话 | 更新弹窗正文 |
| `recipes.version` | 菜谱库版本 | 与本地比对，决定是否拉索引 |
| `recipes.indexUrl` | 索引地址 | 发现菜谱有新版后拉取 |

## 4. 网络接口（HTTP）

| 接口 | 方法 | 用途 | 调用时机 | 超时/降级 |
|---|---|---|---|---|
| `GET {source}/version.json` | GET | 拿总版本 | 冷启动、手动刷新、设置检查更新 | 5s；双源互备；失败用本地 |
| `GET {recipes.indexUrl}` | GET | 拿菜谱索引 | 仅当 `recipes.version` 变新 | 8s；失败不动本地列表 |
| `GET {base}/{file}` | GET | 下单个餐谱 JSON | 按索引 diff | 8s/个；整批 20s；单个失败跳过 |
| `GET {app.apkUrl}` | GET | 下载 APK | 用户点「更新」 | 进度条；失败重试 2 次；可取消 |
| `GET {app.changelogUrl}` | GET | 更新日志正文 | 设置页打开 | WebView；失败提示 |
| **延迟探测** | GET/HEAD | `version.json` 轻量请求计时 | 自动模式启动时 | 5s；结果缓存 24h |

**双源**：`GitHub raw` 与 `Gitee raw` 两套 base URL，写在 `BuildConfig`，结构镜像。

**拉取策略**（设置项）：

| 值 | 行为 |
|---|---|
| `auto` | 测双源延迟择优，失败自动切备用 |
| `github` | 只用 GitHub；连续失败提示切换 |
| `gitee` | 只用 Gitee；连续失败提示切换 |

## 5. 本地接口 / 存储

| 模块 | 存储内容 | 谁用 |
|---|---|---|
| `RecipeStore` | 本地餐谱 JSON（filesDir）+ assets 出厂默认 | 列表、详情、搜索 |
| `SettingsStore`（DataStore） | 深色模式、拉取方式、上次 version、延迟缓存、减弱动画 | 设置页、UpdateService |
| `DraftStore` | 调配/缩放后的本地草稿（不上传） | 调配抽屉、另存 |
| `assets/recipes/` | 出厂默认餐谱 | 首次安装、本地损坏兜底 |
| `LocalVersion` | 本地 `app.versionCode` + `recipes.version` | 与云端比对 |

---

## 6. 搜索匹配接口

| 输入 | 规则 | 用于 |
|---|---|---|
| 查询词 ≥3 字符 | 汉字子序列 / 全拼包含 / 拼音首字母包含，任一命中 | 列表过滤 |
| 查询词 &lt;3 字符 | 不过滤 | 列表 |
| 分类/标签/热量区间 | 与搜索 **AND** 叠加 | 列表筛选 |

---

## 7. 调配算法接口（App 内）

| 输入 | 输出 | 说明 |
|---|---|---|
| 目标热量 `E_target` 或 目标重量 `W_target` | 新的 `items[].weight` + 重算 totals | 按 `healthWeight` 缩放；`locked` 跳过 |
| 当前餐谱 v2 | 调配后草稿 | 不覆盖云端 JSON |

算法细则见主方案 §8。

## 8. 设置项（DataStore 键）

| 键 | 值 | UI |
|---|---|---|
| `theme_mode` | `system` / `light` / `dark` | 深色模式 |
| `pull_source` | `auto` / `github` / `gitee` | 拉取方式 |
| `reduce_motion` | bool | 跟随系统减弱动画（预留开关） |
| `last_recipes_version` | string | 同步比对 |
| `last_app_version_code` | int | 更新比对 |
| `preferred_source_latency` | map | 自动模式测速缓存 |

## 9. 云端仓库路径约定

| 路径 | 内容 | 谁写 | 谁读 |
|---|---|---|---|
| `version.json` | 总版本 | 发布脚本/人工 | App 启动 |
| `CHANGELOG.md` | 更新日志 | 发布 | 设置 WebView |
| `app/yurecipe-vX.Y.Z.apk` | 安装包 | 发布 | 更新下载 |
| `recipes/index.json` | 菜谱索引 | 发布/迁移脚本 | App 菜谱同步 |
| `recipes/<id>.json` | 餐谱 v2 | recipe-nutrition 技能 | App |
| `images/<id>.*` | 菜谱图（预留） | 发布 | App 图片 |
