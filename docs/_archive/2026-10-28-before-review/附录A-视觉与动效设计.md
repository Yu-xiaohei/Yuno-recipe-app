# 「于の食谱」视觉与动效设计 · 附录 A（HyperOS 4 版）

> 对应主方案 v2 · 视觉基调：**小米 HyperOS 4「柔光玻璃 / 生命感美学」**
> 调研来源见 A7。明确一点：**小米官方未发布带 dp/曲线/材质参数的完整开发者设计系统**，本规范区分「官方明确 / 官方画面观察 / 项目实施规则」，数值为项目校准值，不冒充官方令牌。

---

## A1. 设计原则（HyperOS 4）

| 原则 | 落到本 App |
|---|---|
| **生命感美学** | 材质、光线、触摸、位移连续反馈；玻璃随背景变色变明暗；点按出局部光感，拖动光效跟手 |
| **内容优先 / edge-to-edge** | 页面背景延伸到系统栏后方；顶栏/底栏是**悬浮局部表面**，不透明矩形不得截断内容 |
| **空间连续性** | 展开/收起/切换用弹性位移 + 形状插值；动效结束稳定落位，不回弹越界 |
| **柔光玻璃（非死板磨砂）** | 真实背景模糊 + 半透明色调 + 连续圆角高光 + 形状一致阴影 + 可读性遮罩 + 触点光 |
| **形状家族统一** | 连续圆角 / 超椭圆 / 胶囊 / 圆形，同层级不混用生硬圆角与超椭圆 |
| **动效可关** | 支持系统「减少动态效果」；关闭后仍保留清晰状态变化 |

## A2. 材质系统（柔光玻璃）

### A2.1 页面骨架（强制层级）

```
1. 全屏页面背景（edge-to-edge）
2. 可滚动主体内容（可钻到顶部/底部玻璃后方）
3. 大标题 + 页内搜索 + 主要内容层
4. 局部悬浮：顶部操作、底部导航胶囊、主 FAB
5. 临时反馈：Snackbar / 菜单 / 对话框（层级最高，不得被底栏遮挡）
```

### A2.2 玻璃材质六层（缺一不可）

| 层 | 要求 |
|---|---|
| 1 背景模糊 | **真实采样后方内容**，不是只调前景透明度 |
| 2 半透明色调 | 随背景明暗/主题变化，不固定灰白 |
| 3 高光/折射边 | 沿连续圆角轮廓；顶部/起始侧亮，底部/结束侧暗 |
| 4 局部阴影 | 与裁剪形状一致，**禁止矩形阴影底板** |
| 5 可读性遮罩 | 保证文字/图标/选中态对比 |
| 6 触点光效 | 点按位置局部发光；拖动时光感跟手 |

### A2.3 五档材质（对应「玻璃强度」设置，默认「标准」）

| 档位 | 模糊 | 遮罩 | 折射 | 用途 |
|---|---|---|---|---|
| 最弱 | 低 | 较高实体 | 无 | 省电 / 低端机 |
| 较弱 | 轻微 | 中 | 边缘高光 | 性能优先 |
| **标准** | 自适应 | 自适应 | 局部高光 | **默认** |
| 较强 | 清晰透色 | 低 | 明显 | 质感优先 |
| 最强 | 强透色 | 很低 | 明显 + 动态光 | 演示；仍禁止变成不透明白块 |

> 低性能设备可降采样分辨率/光数量，但**不得用不透明矩形代替局部玻璃**。

### A2.4 形状与尺寸（项目校准值）

| 元素 | 规格 |
|---|---|
| 底部导航胶囊 | 高 **56dp**，内边距 4dp，选中镜片高 **48dp**（拖动时四边内缩 2dp） |
| 独立 FAB | 与胶囊等高 **56dp** 圆形，与胶囊间隔 **12dp**；不是导航目的地，不移动镜片 |
| 顶部圆形操作钮 | 独立圆形玻璃面，多个操作之间留间隔，**不合并成椭圆** |
| 紧凑标题条 | 真实背景磨砂，下边缘渐隐；滚动折叠后内容从玻璃后方经过 |
| 卡片 | 轻染色玻璃或低对比实体表面；高密度列表用大留白 + 弱分隔，**不强制包卡片** |
| 搜索/筛选 | 低高度胶囊 |
| 超椭圆 | 主要按钮、导航镜片、强调容器 |

### A2.5 品牌色用法（HyperOS 4 小米蓝白）

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 · 澎湃蓝 | `#3482FF` | 主按钮、选中态、链接、进度、FAB 图标 |
| 主色按下 | `#2B6FE0` | 按压态 |
| 浅色背景 | `#F7F7F8` | 页面底 |
| 浅色表面 | `#FFFFFF` | 卡片/玻璃容器 |
| 深色背景 | `#000000` | 深色底（HyperOS 近纯黑） |
| 深色表面 | `#1C1C1E` | 深色卡片 |
| 次级文字 | `#8E8E93` | 辅助、时间戳 |
| 分割 | `#E5E5EA` / `#2C2C2E` | 弱分隔 |
| 成功 / 警告 / 超限 | `#34C759` / `#FF9F0A` / `#FF3B30` | 状态 |

- 活力橙 `#FFA502` **退出界面主色**，仅品牌 Logo 素材可用。
- 玻璃色调来自背景与场景，禁止固定灰白；浅色/深色/复杂图片/高对比都要验证可读性。
- 底部导航目的地：**图标在上 + 小文字在下**；镜片宽度=槽位等分宽。

## A3. 动效清单（生命感 · 跟手 · 可打断）

> 曲线以**弹性位移**为主；触觉角色跟随语义。

### A3.1 启动 / 页面过场

| # | 场景 | 动画 | 要点 |
|---|---|---|---|
| T1 | 冷启动 Logo | 缩放浮现 | 生命感：轻微回弹后落位 |
| T2 | 启动 Spinner | 柔光圆环 + 光感扫过 | 光场感，非死板转圈 |
| T3 | 启动页 → 主页 | 空间连续：内容从标题下方生长 | 避免整页机械淡出 |
| T4 | 列表 → 详情 | **共享位置 + 形状插值**（卡片→大图/标题） | 弹性落位，无尺寸跳变 |
| T5 | 详情 → 列表 | 逆向共享位置 | 下滑手势可中断 |
| T6 | Tab 切换 | **镜片液态位移**到目标槽位 | 逐帧跟手拖动；点按隔项时内容淡出后直达，不横扫中间页 |
| T7 | 打开调配抽屉 | BottomSheet 弹簧上滑 + 背景渐进模糊 | 锚定触发点；玻璃只在自身裁剪区 |
| T8 | 关闭抽屉 | 跟手下移 + 弹簧回弹 | 可拖拽取消 |
| T9 | 子页 | 连续位移 + 共享锚点 | 横竖屏/分屏不整页闪白 |
| T10 | 对话框 | 从锚点缩放/展开 | 尺寸由内容定，不默认撑满 |
| T11 | Snackbar | 出现在**底栏之上** | 预留安全区 + 导航高度 |

### A3.2 底部导航（主秀场 · 最高优先级）

| # | 交互 | 行为 |
|---|---|---|
| N1 | 点按切换 | 确认前只做收缩反馈；确认后镜片**连续位移**到目标（弹簧吸附一次） |
| N2 | 拖动镜片 | 逐帧直跟；速度只影响镜片形变与吸附初速度；松手吸附最近槽位 |
| N3 | 拖动形变 | 镜片四边内缩 ~2dp，随速度受限形变；面板橡皮筋 ≤4dp |
| N4 | 按压 | 面板投影静止，**只缩放玻璃表面**；图标/文字围绕**自身中心**缩放 |
| N5 | 光效 | 拖动光感跟随手指；可有按压深度折射/色散/内阴影；**Android 若 GPU 采样错位/彩条，退回真实背景模糊** |
| N6 | 静止态 | 镜片不叠常驻双层高光；内阴影贴同一外轮廓 |
| N7 | 等分 | 中英文/仅图标/仅文字/图标+文字 都要视觉等分；镜片宽度=目的地等分宽（非小圆点） |

### A3.6 手势与降级

| 项 | 约定 |
|---|---|
| 下滑关闭详情 | 跟手 + 弹簧；可中断 |
| 下拉刷新 | 跟手，光效跟指针 |
| 拖底栏镜片 | 见 N2 |
| 拖动取消 | 控件沿可理解路径回原位 |
| 减少动态效果 | 过场→短淡入淡出；停装饰循环与光效；保留状态与层级 |
| 低性能 | 降采样/降光数量；形状层级透明关系保留 |
| 玻璃异常 | 退回真实背景模糊或半透明遮罩，不花屏、不变不透明白板 |

## A4. 页面级规格

### A4.1 启动页
edge-to-edge；Logo 生命感浮现；柔光 Spinner；进入主页空间连续。

### A4.2 列表页
- 大标题 + 页内搜索胶囊
- 筛选 chips 低高度胶囊
- 列表：大留白、弱分隔；卡片非强制
- **底部悬浮玻璃胶囊导航**（主秀场）+ 可选独立圆形 FAB
- 内容从底栏后方滚过

### A4.3 详情页
- 顶图 16:9 / 无图占位
- 顶部圆形玻璃操作（刷新/更多）
- 三卡可用轻染色玻璃；数字用主题色
- 明细手风琴；来源外链
- 页脚版权无玻璃小字

### A4.4 调配抽屉
- BottomSheet 玻璃，锚定触发
- 目标热量/重量大数字 + 快捷键
- 权重只读；预览/另存/取消
- Snackbar 反馈层级高于底栏

### A4.5 设置页
- 分组留白 + 弱分隔（非卡片森林）
- HyperOS 风格 Toggle/行项（可用 miuix-preference）
- 页脚版权小灰字

## A5. 实现选型与可行性

### A5.1 可行性结论（对照 NexioSchedule 实证）

| 效果 | 可行性 | 说明 |
|---|---|---|
| Squircle 超椭圆 | ✅ 完整 | miuix-squircle |
| 悬浮玻璃胶囊 + 液态镜片拖动/形变 | ✅ 完整 | 56/48dp、跟手、弹簧吸附 |
| 真实背景模糊（内容滚过玻璃下） | ✅ 完整 | miuix-blur |
| 渐进模糊 / 顶栏折叠玻璃 | ✅ 完整 | Nexio 已验证 |
| 触点光 / 边缘光 / 拖动光 | ✅ 可做 | 自绘 + 手势坐标 |
| 弹簧位移 / 共享元素 / 形状插值 | ✅ 完整 | Compose |
| 按压折射/色散 | ⚠️ 近似 | 33+ AGSL；31–32 RenderEffect；29–30 仅高光+半透明 |
| 与 MIUI 系统应用像素级一致 | ⚠️ 不保证 | 小米未公开官方令牌，参数为校准值 |

> **minSdk 策略（已定）**：`minSdk = 29`（Android 10 也能装），**质感以 API 31（Android 12）为基线**开发；29–30 走降级（半透明+高光+形状阴影，无真模糊），31+ RenderEffect 真模糊，33+ AGSL 折射。保证低版本用户可用。

### A5.2 依赖

| 路径 | 内容 |
|---|---|
| **首选组件库** | **Miuix**（`top.yukonga.miuix.kmp:miuix-ui` 等）— Compose Multiplatform，HyperOS 风格 |
| 玻璃/模糊 | `miuix-blur` + `miuix-shader`；必要时叠 Haze 做图片下垫 |
| 形状 | `miuix-squircle` 超椭圆 |
| 导航 | `miuix-nav` 或自研液态底栏（严格按 A3.2） |
| 设置项 | `miuix-preference` |
| 降级 | API 33+ 真折射；31–32 RenderEffect；29–30 半透明+高光+形状阴影 |
| 主题 | MiuixTheme + keyColor `#3482FF`（澎湃蓝） |

```kotlin
implementation("top.yukonga.miuix.kmp:miuix-ui:<ver>")
implementation("top.yukonga.miuix.kmp:miuix-preference:<ver>")
implementation("top.yukonga.miuix.kmp:miuix-blur:<ver>")
implementation("top.yukonga.miuix.kmp:miuix-squircle:<ver>")
implementation("top.yukonga.miuix.kmp:miuix-nav:<ver>")
```
