# 附录 A：视觉与动效 v3

> 2026-10-28。保留现有 Figma 的液态玻璃方向。下列参数均为项目设计值，不宣称为小米官方令牌。旧稿的库版本、模块、系统效果和“完整可行”结论未经本轮工程验证，不沿用为承诺。

## A1. 内容与材质

浅底、白卡、蓝色操作强调，品牌图标保留橙色。底部导航、搜索、筛选菜单与悬浮按钮使用液态玻璃方向：背景透色、边缘高光、局部光感与受限形变。普通营养正文优先清晰读取。

Figma 使用透明、模糊、高光近似材质；Android 需独立实现与真机验证。用户要求的液态玻璃不能仅通过给前景加高斯模糊来验收。具体采样和折射管线在技术原型阶段决定。

深色主题与复杂图像下确保文字和选中态可辨识；高对比、减少动态及性能降级均保留交互语义。异常时使用清晰的简化材质，不出现花屏或影响点击。

实际建立语义变量：背景、表面、主/次文字、操作、警告、危险、分割、间距、圆角和动效。亮暗模式共用角色名，避免散落硬编码。

## A3. 导航与页面过场

三个目的地配餐/食谱/设置，图标上文字下，镜片宽度随槽位等分。独立操作 FAB 不作为第四个目的地。

点按切换：镜片连续位移、适度弹簧落位；快速连续点按以最近操作为准。跨项切换不强制让用户观看中间页面。

拖动镜片：逐帧跟手，松手吸附，受限形变，不越界；滑块和搜索输入优先自己的手势。

正文允许短距离交错退场与入场，避免长列表逐项动画阻塞点击。食谱卡片→详情可共享图片、名称和轮廓，返回恢复列表位置。抽屉跟手关闭并妥善处理未保存草稿。

## A4. 微动效与反馈

| 场景 | 行为 |
|---|---|
| 按钮 | 局部按压/光感反馈，恢复稳定 |
| 食材展开 | 连续高度与箭头旋转，保留阅读位置 |
| 调配滑块 | 即时预览，数字与食材同时更新；不每次拖动都触发完整入场动画 |
| 保存 | 成功状态与下一步明确，不能只给一闪而过的对勾 |
| 同步 | 文本状态区分本地已保存、待同步、失败和冲突 |
| 后台刷新 | 保留现有内容和滚动位置，只更新同步标识 |
| 初次加载 | 无可用内容时使用骨架；失败提供重试 |

参考时长：按压80–120ms、页面240–380ms、抽屉约300ms；减少动态时以约120ms淡变替代装饰位移。均为调校起点，不是跨设备强制指标。

## A5. 实现前必须验证

Android UI 库、Compose 版本、最低/目标系统版本及背景采样方案均需锁定后验证。先做包含滚动内容、悬浮栏、滑块和深色主题的小原型，再决定是否使用候选 Miuix/Haze 或自绘组合。当前文档不保证某个库存在特定模块，也不以 API 等级单独保证折射效果。

先保证布局、目标反馈、可操作与可读，再验证玻璃和过场，最后做装饰光效。公共发布需测至少一台低性能设备和目标主力设备；目标刷新率、帧预算由实际设备基线确定。

## A6. 验收

- 浅色、深色、图片背景、字体放大时可读。
- 玻璃轮廓与高光一致，无矩形阴影底板及采样错位。
- 底栏与顶栏避开系统安全区，Snackbar 不被底栏遮挡。
- 连续操作可打断，不叠加多个不可取消动画。
- 减弱动画停止装饰循环，状态仍清晰。
- 滑块、键盘、屏幕阅读器与点击区域可用。
- Figma 截图、原型连接和真机验证分别报告，不互相冒充。
