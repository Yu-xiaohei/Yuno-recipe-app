# 存储与分发接入基线

> 2026-10-28 用户确认：123 云盘同步私人配餐，阿里云 OSS 仅存公共食谱和图片，GitHub/Gitee 分发 APK。

## 职责和客户端接入

| 内容 | 服务 | App 接入方式 |
|---|---|---|
| 私人配餐及目标快照 | 用户主动配置的 123 云盘 WebDAV | 专用目录、用户授权、先本地保存再同步 |
| 公共食谱 JSON、索引及图片 | 阿里云 OSS | 已发布的公共 HTTPS 地址，缓存及校验后使用 |
| 食谱镜像 | GitHub/Gitee，按实际部署启用 | 与公共索引采用同构路径及 revision/hash；失败回退 |
| APK、版本说明与发布校验信息 | GitHub/Gitee | 用户主动下载并调用系统安装；检查完整性和签名兼容 |

私人配餐不写入公共 OSS 或仓库。首版不增加私人 OSS 同步后端，不把 Bucket 域名填入 WebDAV 设置。OSS 发布由维护端完成，App 只读公开内容；无需在 APK 中放发布 AccessKey 或接入 OSS 上传 SDK。

## 已核实和待验证

[123 云盘官网](https://www.123pan.com/)明确提供 WebDAV。该说明不能证明某个用户账号已开通读写，也不能证明 ETag 和条件写入符合本应用的冲突协议。接入测试需验证指定目录的列举、读写和删除、ETag、If-Match、If-None-Match，以及并发和鉴权失效。测试仅操作专用测试目录，不删除其他文件。缺乏可靠条件写入时，执行既定的显式备份/恢复降级，保留双方数据。

本轮未登录 123 云盘、未读取凭据，亦未对用户空间进行写入。账号端点、应用授权和服务能力留待接入时通过 App 配置并验证。

阿里云 OSS 是对象存储接口，不能直接当作 WebDAV。其 [Android 凭证文档](https://help.aliyun.com/zh/oss/developer-reference/android-configure-access-credentials)区分服务端长期凭证和移动端临时授权。当前选择公共资源只读访问，无需新增私人数据的 OSS 授权链路。

OSS 的具体 Bucket/区域、公共读取地址或 CDN 域名尚未配置。本地开发使用内置参考数据及测试 HTTP 源；发布前确认公共路径、读取权限、缓存策略、版本索引、hash、失败回退及外网可访问性。只公开已授权的食谱和图片，不能为了读取公共目录而开放私人数据目录。

GitHub/Gitee 现有 `version.json` 公开入口在本次检查均返回 404；尚未部署成功。OSS 与仓库镜像必须分别验证，不能仅凭仓库存在宣称三源可用。
